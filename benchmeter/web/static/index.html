Every measurement is bounded by the instrument taking it. Here the instrument is the machine itself, so it is characterised first, with a fixed task whose duration cannot vary.

Note

A ruler marked in millimetres cannot measure anything smaller than a millimetre. The same limit applies here, and it is worth knowing before chasing a one percent regression.

Procedure

  1. Both commands run three times, discarded, to warm caches.
  2. Each round runs A and B once, in random order.
  3. Rounds repeat until the answer is clear or time runs out.
  4. Paired rounds are resampled to build the interval.
