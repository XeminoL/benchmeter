benchmeter

Which of two snippets is faster, or whether the difference is noise

Both boxes start identical, so the honest answer is no conclusion.

What this is doing

Both snippets run once per round, in a shuffled order, until the time budget is spent. Measuring all of the baseline and then all of the variant would let the browser warm up in between, and that drift would land on whichever ran second.

Before the comparison, a fixed workload runs repeatedly to establish what this browser can resolve. Since that workload never changes, the variation observed in it belongs to the machine. A difference smaller than that floor is not reported, however convincing the interval looks.

The statistics run here are the same code as the command-line tool: the median, the median absolute deviation, a bootstrap over paired rounds, and the resolution floor, executed in the browser through Pyodide. Timing comes from performance.now(), so the numbers are this machine's.

Where it differs from the tool

A page cannot start a process, so this measures JavaScript in the browser rather than commands on the host. The installable version times any command and reaches a resolution the browser clock cannot.
